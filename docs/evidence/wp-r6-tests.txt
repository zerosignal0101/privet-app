       Also asserts no content-URI probe happened for a real path.

       Asserts the old wording is retained exactly.
  6 -> "a throwing or unreachable content URI is treated as unreachable"
       Covers throw, false, and the case where the staged copy IS on disk (must
       not fall through to it).
  7 -> "regression: the staged copy is never treated as the file's identity"
       Two sends of the same file name -> two staged paths, two mappings, each
       row judged by its own URI. Locks the invariant that once a reference is on
       record the staged copy's existence is never consulted.
